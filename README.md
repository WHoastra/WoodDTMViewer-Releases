# WoodDTMViewer downloads

Installer releases for **WoodDTMViewer**, the DTM viewer and measuring tool for subsea survey: load the large gridded DTM `.xyz` exports straight from processing, several surveys in one window, measure in 2D and 3D, compare surveys, put pipe routes, drawings and waypoints on top, export a GeoTIFF for the nav software, and let the rest of the survey office look over the network. Runs on your own Windows 10 / 11 PC; nothing leaves the ship.

This repository holds the installers only; the source code is not public.

- Website, pricing and documentation: https://whoastra-labs-site.vercel.app/woodsolutions/wooddtmviewer
- All downloads: https://github.com/WHoastra/WoodDTMViewer-Releases/releases
  - `WoodDTMViewer_Setup_<version>.exe`: the full application (16 MB). A newer Setup upgrades in place; projects and settings are kept.

Windows SmartScreen may show a notice on a new publisher's installer: choose *More info*, then *Run anyway*. All installers are built by Whoastra Labs LLC.
